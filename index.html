⚙️ 오늘 자동 처리 현황

    매일 새벽 4시경 기사 수집 → AI 선정 → 브리핑 오디오 → 구독자 메일 순서로 자동 진행됩니다.

    🛠️ 관리자 작업

    기사 다시 수집은 이어서 AI 선정 → 오디오 → 메일까지 자동으로 진행됩니다(5분 이상). 결과는 위 처리 현황에 표시되고, 사이트에는 끝난 뒤 1~2분 안에 반영됩니다.

        🤖 사이트 활용법
        1. 매일 새벽 4시경 기사를 모으고 AI가 어제 기사 중 중요한 것을 골라 오늘 일일 동향(⭐)을 만듭니다.
        2. 📋 일일 동향 복사를 누르면 공유용 텍스트가 복사됩니다.
        3. 목록을 고치려면 기사 옆 ☆/★를 눌러 넣거나 빼고, 위에 나오는 💾 일일 동향 저장을 누릅니다(관리자). 약 1분 뒤 텍스트에 반영됩니다.
        4. 저장 전 변경은 이 브라우저에만 임시로 남고, 새 일일 동향이 나오면 새 목록으로 바뀝니다.
        5. 관리자 모드에서는 🧠(AI 분류 학습 데이터 추가)와 🚫(일일 동향에서 제외) 버튼을 쓸 수 있습니다.
